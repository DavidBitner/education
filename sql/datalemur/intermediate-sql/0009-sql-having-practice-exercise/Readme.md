# Data Science Skills

> **Problem Summary:** Given a table, list the candidate ids of candidates who have more than 2 technical skills.


## Notes & Thoughts
This exercise requires HAVING with multiple conditions.

In this lesson I'm starting to figure out how filtering data actually works. It's a process, when you reference a column with SELECT, you filter with WHERE, group that information with GROUP BY, and then use HAVING to filter again and get what you actually want.
