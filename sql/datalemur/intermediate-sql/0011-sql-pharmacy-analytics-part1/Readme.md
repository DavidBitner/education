> **Problem Summary:** Given a table, write a query to find the top 3 most profitable medicines sold, and how much profit they made.


## Notes & Thoughts
This lesson explains some arithmetic operators.

+, -, *, /, %, ^, -(as a prefix)

SQL arithmetic order follows the order of operations of PEMDAS:
P: Parentheses first
E: Exponents
MD: Multiplication and Division (left to right)
AS: Addition and Subtraction (left to right)
