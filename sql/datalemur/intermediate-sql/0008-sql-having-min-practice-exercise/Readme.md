# SQL HAVING MIN Practice Exercise

> **Problem Summary:** Find all stocks whose open share price was always greater than $100.


## Notes & Thoughts
This lessons explained the difference between WHERE and HAVING.

WHERE is used for single rows, before grouping is applied.

HAVING is applied to aggregated values from groups of rows, after grouping is applied.
