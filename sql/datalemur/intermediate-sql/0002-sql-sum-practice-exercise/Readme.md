# SQL SUM Practice Exercise

> **Problem Summary:** Given a table, output the total number of drugs manufactured by Pfizer and the total sales for all Pfizer drugs.


## Notes & Thoughts
This is the second exercise inside of the aggregate functions lesson.

While naming column aliases, I was unsure about how the naming conventions for aliases work. It seems that there are two conventions: the first applies when the aliases need to be referenced in other queries, meaning they use snake_case; the second is for displaying information to other people, in which case a readable label is used.
