# SQL Tutorial Lesson: Superheroes' Likes

> **Problem Summary:** Given a table, write a query to categorize superheroes based on their average likes
>* Super Likes: Superheroes with an average likes count greater than or equal to 15000
>* Good Likes: Superheroes with an average between 5000 and 14999
>* Low Likes: Average likes count less than 5000
>
> Display the actor, character name, platform, average likes, and the corresponding likes category.
> Sort by average likes
